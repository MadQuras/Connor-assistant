- [ ] **SOCKS / прокси** — Connor должен работать независимо от системного прокси (как уже частично для Whisper: отключать `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY` при загрузке модели и при необходимости для Gemini, pip, Hugging Face и т.д.).
