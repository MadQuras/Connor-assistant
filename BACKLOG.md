## 🔮 Погода — целевая логика (напоминание)

**Сейчас:** `Whisper → локальный роутер «погода» → открывается браузер (Yandex) → Gemma пишет реплику в текстовую панель КОННОР`.

**Нужно сменить на:**

```
Whisper → локальный роутер «погода»
  → визуальное окно Коннора с погодой (как в preview / dashboard)
     — почти вся информация: температура, ощущается, ветер, влажность, прогноз и т.д.
     — данные через API, не браузер
  → Gemma в фоне пишет реплику в текстовую панель КОННОР
```

**Затронутые файлы (ориентир):**
- `python-core/openjarvis/handlers/weather.py` — убрать `subprocess` → браузер; показать weather-overlay
- `python-core/openjarvis/connor_tools.py` → `get_weather` — тот же путь, парсинг города из фразы
- `python-core/openjarvis/fallback_router.py` — извлекать город («погода в Казани» → arg)
- Новый UI: PyQt overlay или Tauri-компонент «weather card» по макету preview
- API: Open-Meteo / Yandex Weather API / др. — без открытия вкладки

**Не менять:** Gemma только для короткой реплики Коннора; маршрутизация и LLM — в фоне.
